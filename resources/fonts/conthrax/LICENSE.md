# Conthrax Semi Bold

Typeface by Typodermic Fonts Inc. (Raymond Larabie). The lettering of the
Gluta RepubliQ logo.

The webfont (`Conthrax-SemiBold.woff2`) is used under a webfont licence the
clinic owner purchased (confirmed by the owner, 2026-10-24). The free
Typodermic desktop licence does not allow webfont use, so do not replace this
file with a self-converted copy of the free desktop OTF.
